# Morghulis Website

This is the repository for the Morghulis website. It is built with Astro and Tailwind CSS.
For the desktop shell, see the [Morghulis repository](https://github.com/ARKye03/morghulis).

## Getting Started

1. Clone the repository
2. Run `pnpm install` to install the dependencies
3. Run `pnpm dev` to start the development server
4. Open `http://localhost:4321` in your browser
